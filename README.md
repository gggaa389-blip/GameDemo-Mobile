# GameDemo Mobile — نسخة الأندرويد + لعب مشترك عبر نقطة الاتصال

نسخة موبايل من لعبة **Chickensoft GameDemo** (Godot 4.7.2 / C#):
شاشة أفقية كاملة، تحكّم لمسي، ولعب لاعِبَين عبر الشبكة المحلية **بدون إنترنت**.

> **تحميل اللعبة (APK):** من صفحة [Releases](../../releases/latest) — ملف `GameDemo-Mobile.apk`

---

## التثبيت
1. نزّل `GameDemo-Mobile.apk` من صفحة الإصدارات.
2. انقل الملف إلى الهاتف وافتحه.
3. اسمح بـ «تثبيت من مصادر غير معروفة» (وإن ظهر تحذير Play Protect اختر «تثبيت على أي حال»).
4. افتح تطبيق **GameDemo**.

**المتطلبات:** أندرويد 7.0 أو أحدث · معمارية `arm64-v8a` · الحزمة `com.gamedemo.mobile`.

## التحكّم
| العنصر | الوظيفة |
|---|---|
| العصا التناظرية (يسار) | حركة الشخصية — 8 اتجاهات، شدة متغيّرة |
| `JUMP` (يمين أسفل) | قفز (اضغط باستمرار لقفز أعلى) |
| `HIT` | هجوم |
| `SWAP` | تبديل السلاح |
| `II` (أعلى اليمين) | إيقاف مؤقت |
| السحب على النصف الأيمن | تدوير الكاميرا |
| نقرة قصيرة | تعمل على قوائم اللعبة |

## اللعب مع صديق (بدون إنترنت)
1. الهاتف الأول: **الإعدادات ← نقطة اتصال الهاتف** وفعّلها (لا حاجة لبيانات).
2. الهاتف الثاني: اتصل بشبكة الهاتف الأول.
3. الهاتف الأول: **HOST GAME**.
4. الهاتف الثاني: يظهر اسم اللعبة تلقائيًا في «GAMES FOUND ON THIS NETWORK» فيضغط عليه، أو يكتب `192.168.43.1` ويضغط **JOIN**.
5. على الجهازين: **New Game** → يظهر كل لاعب عند الآخر.

يظهر في أعلى الشاشة: `LAN: connected` أو `LAN: waiting for the other phone...`

## كيف تعمل المزامنة
* كل هاتف يملك شخصيته بالكامل محليًا → **لا تأخير في الاستجابة**.
* إرسال 30 حزمة/ثانية (موقع + دوران + سرعة) على قناة غير موثوقة مرتّبة.
* اللاعب البعيد يُرسم باستيفاء بين لقطتين بتأخير ~90 مللي → حركة ناعمة بلا اهتزاز.
* مصافحة قبل البدء، وتعطيل محاكاة نسخة اللاعب البعيد (لا تسقط ولا تجمع العملات بالنيابة عنك).

## إعادة البناء
```bash
git lfs install && git lfs pull          # أصول المستودع عبر Git LFS
find . -name "*.import" -not -path "./.godot/*" -delete
godot --headless --path . --import        # Godot 4.7.2 .NET
dotnet build GameDemo.csproj -c ExportRelease   # .NET SDK 9
godot --headless --path . --export-release "Android" build/gamedemo.apk  # JDK 17 + build-tools 34
```
